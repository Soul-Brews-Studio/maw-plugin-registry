## Honest Feedback (session-specific friction)

1. **Wrong repo for the skill.** `/rrr` is designed for Oracle repos with a `ψ/`
   vault. Running it in `maw-plugin-registry` means we created `ψ/` inside a repo that
   doesn't want it, and the resulting retro lives in a directory that is not part of
   anyone's vault. It will get lost or accidentally `git add`-ed someday.

2. **10-day session continuity.** The jsonl spans 2026-05-20 to 2026-05-30. Anything
   I might have remembered from the first `/rrr` attempt is long compacted. The "real
   timestamps from jsonl" extraction returned only 3 messages — there is no rich
   timeline to mine because there was no rich work. The skill assumes a working
   session; an idle 10-day gap is a degenerate case.

3. **Tool/permission churn at the start.** The system reminders this turn loaded
   ~140 tool schemas, MCP server instructions, and the full `/rrr` skill body
   (~7 KB of inline instructions) twice. None of that was needed to write three
   small files. The startup overhead is heavier than the actual work.

## Lessons Learned (generalizable)

- **When a skill's preconditions fail, ask the human before falling through to the
  "last resort" path.** Falling through silently produces correct-looking output in
  the wrong place. A one-line confirmation costs nothing and prevents `ψ/`-shaped
  litter in repos that aren't Oracles.

- **A near-empty `.jsonl` is a signal, not noise.** If timeline mining returns 2–3
  messages spanning many days, the honest retro is "this session had no substantive
  work" — not a padded narrative built from `git log` of prior sessions. Attributing
  prior work to the current session is the inflation pattern the anti-rationalization
  table warns about.

- **Never let a retro touch unrelated uncommitted work.** Even when the working tree
  has a dramatic-looking diff (here: 44 K-line delete), the retro's job is to
  describe, not to stage, commit, revert, or "tidy". Scope is the retro file and its
  sibling lesson + metrics row — nothing else.
